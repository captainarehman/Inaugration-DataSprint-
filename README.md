This is a Interactive WebPage for the [Data Sprint Hackathon 2026](https://www.linkedin.com/feed/update/urn:li:share:7485606713493176321/) 

## What it does
- To be very short, it uses Java Script to capture the click or response rate.
- When the user clicks or whatever. It starts to rotate the elements in the orbit at very fast pace, whilst constantly bringing them closer.
- After they're brought, a small flash appears and shows a hacakathon "_button_" and then redirects to the TechShala Event Webpage
